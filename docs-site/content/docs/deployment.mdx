---
title: Deployment
description: Run struggletime-server on a small VPS.
---

One small VPS can run the API. Clients seal time into buckets first, so
write load stays modest. The desktop app does **not** embed this server.

```bash
make server
# or:
cd rust && cargo build --release -p st-server
./rust/target/release/struggletime-server --bind 0.0.0.0 --port 18765
```

Environment (see `.env.example`): `PORT`, `BIND`, `SERVER_DB`, OAuth/Slack secrets as needed.

Example systemd unit:

```ini
[Service]
WorkingDirectory=/opt/struggletime
ExecStart=/opt/struggletime/rust/target/release/struggletime-server --bind 0.0.0.0 --port 18765
Restart=on-failure
```

Put Caddy or nginx in front for TLS. Serve `docs-site/out` under `/docs/` or let the process serve static files next to the SPA.
